# Documentação da API — Gasto Certo

## 1. Visão geral

A API REST do Gasto Certo foi desenvolvida em Laravel utilizando Laravel Sanctum para autenticação por tokens.

A API permite realizar operações de cadastro e autenticação de usuários, gerenciamento de categorias e gerenciamento de gastos.
